FFmpeg source for Vidsmith Android 1.2 (6)

Vidsmith Android dynamically links the FFmpeg project's libavformat, libavcodec and libavutil to package QuickTime MOV files. FFmpeg is licensed under the GNU Lesser General Public License, version 2.1 or later.

Version 1.2 (6) uses the same FFmpeg 6.1.6 source and Android build script as version 1.2 (5). The matching FFmpeg libraries in the two packages are byte-for-byte identical.
